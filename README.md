**Команда Cicada 3301 · Хакатон «Кибер102» · Уровни 1–4**

## Как устроена работа с фактами

Карточки строятся из записей каталога и данных источников. Языковая модель извлекает структурированные условия запроса. Исполнитель выбирает и вызывает типизированные инструменты, проверяет результат и формирует ответ. Названия, даты, цены и адреса берутся из результатов инструментов. Трасса сохраняет запрос, вызовы и записи-основания ответа.

Неизвестные значения хранятся как `null`. Неизвестная цена не считается бесплатным входом. Отменённые и явно распроданные сеансы исключаются из подборок, постоянная карточка сохраняется. Планировщик проверяет бюджет на всю группу и не подтверждает маршрут или время окончания, если соответствующих данных нет. Адрес пользователя не передаётся языковой модели.

В снимке передачи сохранены 78 мероприятий, 3 источника каталога и 52 записи проверки конкретных сеансов. Это количество записей в базе, включая непубличные статусы. Источники включают Башоперу, Русский драматический театр РБ и Русский театр Стерлитамака. Страницы Кассы.ру используются для сопоставления сеансов, изображений и статуса продажи. Ошибка загрузки источника не подменяется отметкой об успешном обновлении.

## Архитектура и запуск

Стек: Python 3.12, FastAPI, SQLAlchemy, Alembic, aiogram, Node.js 24, Next.js 16, React 19 и TypeScript. Основной Compose-контур использует PostgreSQL 17. Размещённая демонстрационная версия работает на SQLite и systemd. Бот, web и сборщик обращаются к общему API.

Нужны Docker с Compose v2 и свободные локальные порты 3000 и 8000. Запуск выполняется из корня отдельного клона. Создайте собственный `.env` по [`.env.example`](.env.example) и [описанию переменных](docs/configuration.md). Рабочие ключи хранятся вне Git. Для просмотра сайта без переключения действующего бота оставьте `TELEGRAM_BOT_TOKEN` пустым. Задайте собственные секреты и URL, затем выполните:

```bash
docker compose up --build -d
docker compose ps
```

Сайт нового Docker-экземпляра доступен на `http://localhost:3000`, документация API на `http://localhost:3000/api/docs`. Новая PostgreSQL-база пуста. Для проверки собранных данных приложен [обезличенный снимок SQLite](data/README.md). Перенос SQLite в PostgreSQL требует отдельного проверенного преобразования данных.

Для локальной Windows-разработки нужны Python 3.12, Node.js 24 и PowerShell. После подготовки отдельной конфигурации используйте `./run.ps1 -Install`. Заполните `.env` своими ключами и путями выбранного окружения. Одновременно с сервером вторую polling-копию `@kiber102rfbot` не запускают.

Для запуска Python-проверок на Windows:

```powershell
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.lock.txt
.venv/Scripts/python.exe -m pytest -q
```

Тестовые данные создаются только в изолированных базах. PostgreSQL-проверки требуют отдельного `POSTGRES_TEST_URL` и без него пропускаются. Linux-команды, frontend-проверки и полный порядок установки описаны в [развёртывании](docs/deployment.md) и [проверках](docs/testing.md).

## Модель и стоимость

Используем `deepseek/deepseek-v4.1-flash-1017` через OpenRouter. Для проверки организаторами выделен отдельный ключ с общим лимитом 0,50 USD без сброса. Сервер ограничивает расходы и при недоступности модели переходит к обычному поиску.

Стоимость считается по входным и выходным токенам: `(input_tokens × input_rate + output_tokens × output_rate) / 1 000 000`. Фактический расход берётся из ответа провайдера.

Измеренный диалог из пяти реплик стоил **0,0004114 USD**, примерно **0,034 рубля, или 3,4 копейки**. Для пересчёта использован курс 82,1516 рубля за 1 USD на 14 ноября 2026 года.

Расчёт: `0,0004114 USD × 82,1516 рубля за 1 USD ≈ 0,034 рубля`.

Это результат одного диалога, не среднее по независимому набору. Тарифы, лимиты и расчёт приведены в [описании интеграций](docs/integrations.md).

## Что важно учесть при приёмке

- Холодный запуск полного Compose-контура с PostgreSQL 17 за 10 минут и перенос серверных данных из SQLite ещё требуют отдельной проверки.
- Прямое обновление `rusdram.ru` с демонстрационного сервера завершается ошибкой подключения. Исторические записи сохранены. Башопера и театр Стерлитамака успешно обновлялись при последней проверке.
- Реестр подключает источники поддерживаемых форматов. Для произвольного нового формата нужен отдельный адаптер. Живая доставка Telegram-уведомлений отдельно не подтверждена.
- По §10 в итоговом репозитории оставлен `.env.example` без действующих ключей. Рабочие `.env`, личные переписки и приватные архивы исключены. Порядок хранения ключей и замены ранее переданных доступов описан в [инструкции передачи](docs/delivery.md).
- Для промышленного размещения нужно подтвердить web-лицензию TT Knickerbockers и условия использования изображений. Домен демонстрации оплачен до 17 ноября 2026 года.

Трассы и диалоги хранятся 30 дней, обращения и исходные записи источников 90 дней, подписки 180 дней. Ограничения и порядок обслуживания описаны в документации. Оплата билетов, мобильное приложение и полный охват учреждений республики не входят в объём ТЗ.
