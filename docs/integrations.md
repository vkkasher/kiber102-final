# Внешние интеграции

## OpenRouter / DeepSeek

| Параметр | Настройка проекта |
|---|---|
| API | `https://openrouter.ai/api/v1/chat/completions` |
| Модель | `deepseek/deepseek-v4.1-flash-1017` |
| Авторизация | `LLM_API_KEY`, Bearer, только на backend |
| Режим | `LLM_PROVIDER=remote`, `LLM_BASE_URL=https://openrouter.ai/api/v1` |
| Валюта | `LLM_PRICE_CURRENCY=USD` |
| Потолок входа/выхода | `LLM_INPUT_PRICE_PER_MILLION=0.1`, `LLM_OUTPUT_PRICE_PER_MILLION=0.5` |
| Вызов / пользователь за день | `LLM_MAX_CALL_COST=0.003`, `LLM_DAILY_MAX_COST=0.03` долларов |
| Запросы / диалог | `LLM_DAILY_REQUEST_LIMIT=30`, `LLM_DIALOG_REQUEST_LIMIT=10` |
| Токены / вход | `LLM_DAILY_TOKEN_LIMIT=100000`, `LLM_MAX_INPUT_TOKENS=16000` |
| Диалог | `LLM_DIALOG_MAX_RUB=3` |

Отдельный ключ организаторов имеет общий лимит $0,50, `limit_reset=null` и не имеет прав управления аккаунтом. Лимит не возобновляется. Ключ входит только в закрытый пакет конфигурации. Малые проверочные обращения расходуют тот же бюджет. Перед показом проверьте остаток в OpenRouter. Создание нового репозитория не требует нового ключа.

Модель возвращает JSON по схеме. `require_parameters=true` требует поддержку параметров, `data_collection=deny` ограничивает выбор провайдеров, `max_price` передаёт указанные потолки цен. Рассуждения отключены. Автоматические платные повторные попытки через другие upstream отключены. Общий deadline вызова 4 секунды. При отказе, неправильном JSON, исчерпанной квоте или таймауте используется поиск без модели.

Перед сетью в БД резервируется верхняя оценка входа по байтам и максимум 450 токенов ответа. Оценка стоимости в USD равна `(input_tokens × input_rate + output_tokens × output_rate) / 1_000_000`. Фактическая сумма берётся из `usage.cost`. Если провайдер её не вернул, расход неизвестен. При timeout резерв не возвращается автоматически. Резерв хранится в денежном учёте, а не превращается в подтверждённый счёт провайдера.

Для ограничения в рублях используется `LLM_RUB_PER_CURRENCY_UNIT=82.1516`, курс ЦБ РФ на 14.11.2026. Перед более поздней эксплуатацией обновите курс и потолки тарифов. Измеренный диалог из пяти реплик стоил $0,0004114, около 0,034 ₽. Это один внутренний диалог, не средний результат независимого набора. Отчёт находится в [deepseek-dialog.json](evidence/deepseek-dialog.json).

Локальный OpenAI-совместимый режим сохранён как альтернатива. `LLM_PROVIDER=local`, точный loopback URL `/v1` и модель обязательны. Windows-установщик Qwen и llama.cpp запускается только для локального режима. Загруженные веса и старые runtime не входят в финальные исходники. При DeepSeek локальная GPU-модель не нужна.

Документация провайдера: [JSON-схемы](https://openrouter.ai/docs/guides/features/structured-outputs), [маршрутизация и потолок цен](https://openrouter.ai/docs/guides/routing/provider-selection).

## Источники афиши

| Источник | Интерфейс и адрес | Состояние в реестре |
|---|---|---|
| Башопера | HTML `https://www.bashopera.ru/affiche/{month}-{year}/`, текущий и следующий месяцы | Включён для демонстрации |
| Русдрам Уфа | HTML и JSON-LD `https://rusdram.ru/afisha.html` | Включён для демонстрации |
| Русский театр Стерлитамака | `https://rusdramteatr.ru/afisha` и опубликованные тарифы `/bilety` | Выключен, только явный локальный demo-флаг |
| Кассы.ру | Публичные страницы сеансов и трёх площадок на `ufa.kassy.ru`, `sterlitamak.kassy.ru` | Почасовая сверка изображений, цен, окончания и явного статуса продажи существующих сеансов |
| Timepad | REST `https://api.timepad.ru/v1/events`, `TIMEPAD_API_TOKEN` | Адаптер реализован, живой сбор выключен |
| PRO.Культура | REST `https://pro.culture.ru/api/2.5/events/`, `PROCULTURE_API_KEY` | Адаптер реализован, нужен согласованный доступ и региональный фильтр |

Первые три источника являются страницами учреждений, а не предоставленными нам API. Для Timepad и PRO.Культура наличие адаптера не означает полученный партнёрский доступ. Точный реестр, политика и дополнительные URL находятся в [sources.json](../apps/worker/sources.json). До промышленного включения согласуются источники и использование материалов. Сбой, неполный ответ или запрет доступа не обходятся.

Конфигурация управляет включением, расписанием и URL источников с уже поддержанным форматом. В `SourceRegistry` зарегистрированы адаптеры `bashopera`, `rusdram`, `sterlitamak`, `timepad` и `proculture`. Произвольный новый сайт, RSS или API с другим форматом требует отдельного адаптера и его регистрации в коде. Неизвестный идентификатор источника сборщик пропускает. Сверка Кассы.ру подключается отдельно через `ticket_enrichment`.

Путь обработки: fetch → raw/SHA256 → parse → normalize → validate → dedup → verify → moderation. Исходные байты позволяют воспроизвести разбор. Тариф постановки не подтверждает цену выбранного места и наличие билета. Историческая выборка для проверки адаптеров находится в `docs/evidence/sources`, её происхождение записано в `docs/data/source-labels.json`.

Кассы.ру используется как дополнительный HTML/JSON-LD источник, без закрытого API и операций бронирования. Сборщик читает разрешённые robots.txt страницы площадок и сеансов. Ссылку `/buy/` из исходного каталога он преобразует в адрес публичной карточки, не открывая оформление заказа. За проход проверяется не более 120 страниц сеансов, с паузой между запросами. Точное совпадение названия, города, площадки и времени обязательно. Недоступная страница сохраняет предыдущие наблюдения. Неизвестный статус не снимает ранее подтверждённую отметку распродажи. Повторное появление в выдаче требует явного открытия продажи.

Период успешных проходов сборщика задаётся `WORKER_INTERVAL_SECONDS=3600`. После полного сбоя связи с API повтор выполняется через 60 секунд, затем возвращается обычный интервал. Дополнение включается через `ticket_enrichment.enabled` в реестре. Домены добавляются в `SOURCE_ALLOWED_HOSTS`, а при отдельной настройке `SOURCE_ALLOWLIST` также в неё. Изображения привязаны к своему первоисточнику, без подмены фотографией здания. Если изображения нет, интерфейс показывает графическое оформление с категорией и датой. Авторство редакционных фотографий вынесено на `/credits`.

## Telegram и OSRM

Telegram Bot API используется через aiogram в long polling. Токен задаётся в `TELEGRAM_BOT_TOKEN`, API_URL указывает на общий backend. В браузер токен не передаётся.

Подборка отправляется одной статьёй через `sendRichMessage`. После названия каждого события идёт его фотография, затем сведения о сеансе и ссылки. Используются лицензированный `poster_url`, `image_url` или уже связанный с постановкой снимок из `editorial-images.json`. Общие фотографии зданий для замены отсутствующей афиши не используются. Снимки загружаются файлами. Внешняя загрузка использует закреплённый публичный IP, список разрешённых источников, лимит 3 МБ, проверку JPEG/PNG и запрет редиректов. Недоступный снимок пропускается, сведения и ссылки сохраняются.

На странице до трёх событий. Стрелки редактируют исходную статью через `editMessageText`. Число страниц считается по `state.result_count`. Возврат использует сохранённые страницы, новые страницы получают следующий проверенный фрагмент. Снимок подборки действует 15 минут. Кнопки привязаны к пользователю и поиску, после смены запроса прежние не работают. При явно отклонённой статье бот сохраняет текстовую выдачу с теми же ссылками. При неопределённом сетевом исходе автоматической повторной отправки нет. Подтверждения действий используют одноразовые кнопки. Распознавание самостоятельных запросов и уточнений общее для API и бота в `apps/dialogue.py`.

`OSRM_BASE_URL` включает автомобильную оценку маршрута по опубликованным координатам площадок. Без настройки маршрут между разными площадками не подтверждается. Публичный сторонний endpoint по умолчанию не назначен. Оценка содержит источник и время расчёта, не учитывает пробки, парковку и транспортные расходы.
