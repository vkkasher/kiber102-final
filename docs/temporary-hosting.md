# Временное размещение на сервере владельца

Экземпляр предназначен для показа на несколько дней. Сайт и API доступны на `https://kiber102.vkkasher.ru`, бот использует тот же backend и каталог. Основной адрес `https://vkkasher.ru` настроен на перенаправление в этот экземпляр. ИИ работает через OpenRouter с выделенным тестовым ключом DeepSeek и общим лимитом $0,50. Остаток бюджета проверяется в кабинете провайдера.

## Состав и изоляция

| Параметр | Значение |
|---|---|
| Сервер | ОАЭ, `135.136.183.200`, Ubuntu 24.04 |
| Корень экземпляра | `/opt/kiber102` |
| Пользователь | `kiber102`, системный, без интерактивного входа |
| Сайт | Next.js standalone, `127.0.0.1:13102` |
| API | FastAPI, `127.0.0.1:18102` |
| HTTPS | Отдельный Caddy, публичные порты 80 и 443 |
| База | `/opt/kiber102/app/.local/catalog.db`, SQLite WAL |
| Состояние бота | `/opt/kiber102/app/.local/bot.sqlite` |
| Снимки источников | `/opt/kiber102/app/.local/sources` |
| Секреты | `/opt/kiber102/app/.env`, не входят в Git |
| Учёт ресурсов | `kiber102.slice`, предел 1600 МБ и 200% CPU |
| Паспорт экземпляра | `/opt/kiber102/deployment.json` |

Это отдельный временный вариант запуска с существующей SQLite-базой. Перенос данных в PostgreSQL не выполняется. Основной Compose-вариант проекта сохраняется. Node.js, Python-окружение и бинарный файл Caddy находятся внутри корня экземпляра. Службы и базы соседних проектов не используются приложением.

Все компоненты имеют отдельные службы `kiber102-api`, `kiber102-web`, `kiber102-bot`, `kiber102-worker`, `kiber102-proxy`. Они объединены в `kiber102.target` и запускаются после перезагрузки. Автоматического удаления по таймеру нет.

При проверке 15 ноября подтверждены загрузка публичных страниц в браузере, настоящий ответ DeepSeek, семейный план из двух событий и восстановление backup обеих баз. После сверки продажи в публичной выдаче доступны 71 событие из 78 сохранённых записей. Telegram подтвердил имя `kiber102rfbot`, polling работает на сервере. Сообщения людям при проверке не отправлялись, доставка уведомлений остаётся выключенной в конфигурации.

При первом серверном сборе Башопера обновилась успешно. Соединение сборщика с `rusdram.ru` и `rusdramteatr.ru` вернуло `ConnectError`. При финальном аудите исправлен выбор IPv4 на сервере без рабочего IPv6. Повторная загрузка страницы Стерлитамака вернула 39 539 байт, доступ восстановлен. `rusdram.ru` по-прежнему отклоняет соединение с выбранного сервера. Каталог сохранён, сроки актуальности не продлеваются искусственно. Просроченные карточки перестают попадать в подборки после установленного срока проверки, если нет свежего подтверждения конкретного сеанса из дополнительного источника. Timepad выключен, PRO.Культура ожидает партнёрский ключ. Эти ограничения не подтверждают отмену событий.

Дополнительная сверка Кассы.ру включена с общим интервалом сборщика 3600 секунд. Первый проход прочитал 99 страниц сеансов и точно сопоставил 52 записи каталога. Две страницы завершились ошибкой, их данные не изменены. После обработки явной отметки «Свободных мест нет» два сеанса исключены из подборок: «ДЖЕК» и «Восемь любящих женщин». В выдаче 50 событий с изображениями из этого источника. Постоянные карточки распроданных сеансов сохранены. На «Весы» подходящего изображения в проверенных источниках не найдено, используется оформление с датой без служебной подписи. Эти числа относятся к проверке и меняются при следующих проходах.

## Управление

Команды выполняются оператором через SSH на сервере.

```bash
systemctl status kiber102.target kiber102-api kiber102-web kiber102-bot kiber102-worker kiber102-proxy
curl --fail https://kiber102.vkkasher.ru/api/v1/health
journalctl -u kiber102-api -u kiber102-web -u kiber102-bot -n 50 --no-pager
systemctl stop kiber102.target
systemctl start kiber102.target
```

Остановка target останавливает его компоненты и сохраняет данные. Не запускайте вторую polling-копию бота на ноутбуке или другом сервере. Для обновления сначала сделайте backup, затем обновите только этот экземпляр и проверьте readiness и пользовательские сценарии.

## Резервное копирование

```bash
/opt/kiber102/venv/bin/python /opt/kiber102/app/scripts/deploy/native-backup.py
```

Скрипт использует SQLite backup API, проверяет целостность обеих баз и сохраняет конфигурацию и источники в `/opt/kiber102/backups`. Архив содержит токены и частные данные. Его нельзя публиковать или передавать вместе с открытыми исходниками.

## Завершение временного показа

Остановить и отключить автозапуск, сохранив файлы:

```bash
bash /opt/kiber102/app/scripts/deploy/native-remove.sh
```

Удалить экземпляр после остановки и создания приватной резервной копии:

```bash
bash /opt/kiber102/app/scripts/deploy/native-remove.sh --purge
```

Команда с `--purge` удаляет только `/opt/kiber102`, его пользователя и перечисленные службы. Копия остаётся в `/var/backups/kiber102-removal-*.tar.gz`. Скрипт не удаляет соседние проекты, общесистемный Python или журнал systemd. DNS меняется отдельно. Для возврата домена в прежнее состояние уберите две добавленные A-записи `vkkasher.ru → 135.136.183.200` и `kiber102.vkkasher.ru → 135.136.183.200`. Существующая запись `test.vkkasher.ru` не относится к этому экземпляру.

В панели Timeweb на момент размещения срок регистрации домена указан до **17 ноября 2026 года**. Для более позднего показа владельцу требуется продлить домен. Бесплатный HTTPS-сертификат не продлевает регистрацию домена.
