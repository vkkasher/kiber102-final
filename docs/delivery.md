# Итоговая передача проекта

Итоговый закрытый репозиторий [vkkasher/kiber102-final](https://github.com/vkkasher/kiber102-final) содержит исходники функций уровней 1–4, официальное ТЗ, документацию, миграции, тесты, материалы проверок, резервное видео и обезличенный снимок собранного каталога. Сообщение единственного итогового коммита: `Cicada 3301`. Промежуточная история разработки в эту копию не перенесена по решению команды. Соответствующее ограничение §12 отмечено в [матрице приёмки](acceptance.md).

## Проверка готового продукта

- Сайт: [kiber102.vkkasher.ru](https://kiber102.vkkasher.ru/).
- API: [Swagger и контракт](https://kiber102.vkkasher.ru/api/docs).
- Telegram: [@kiber102rfbot](https://t.me/kiber102rfbot).
- Демонстрация: [сценарий](demo.md) и [резервное видео](evidence/demo-5min.webm).
- Результаты парсинга: [снимок базы, состав и SQL-запросы](../data/README.md).

Для просмотра этих компонентов повторный запуск бота и доступ к рабочим ключам не требуется. Доступ к исходникам закрытого репозитория выдаётся приглашением GitHub. Одна ссылка без приглашения не открывает репозиторий постороннему пользователю.

## Конфигурация и секреты

По §10 в Git включён только [`.env.example`](../.env.example) с именами переменных и безопасными примерами. Рабочие `.env`, токены, пароли, секреты подписи, приватные архивы и состояние переписок в итоговую копию не входят. Они сохраняются отдельно у владельца и на действующем сервере. Личные сессии, SSH-ключи и авторизация GitHub не передаются.

Для отдельного экземпляра создайте `.env` по [конфигурации](configuration.md), сгенерируйте собственные секреты и выполните [инструкцию развёртывания](deployment.md). Внешние токены при необходимости передаются адресату отдельно защищённым способом. Для проверки ИИ используется ограниченный тестовый доступ OpenRouter с общим лимитом 0,50 USD без сброса. Остаток бюджета проверяется у провайдера. Не запускайте вторую polling-копию с токеном действующего Telegram-бота.

Ключи, которые ранее передавались вместе с исходниками, следует заменить у соответствующих провайдеров и в окружении работающих служб. Чистый репозиторий не отзывает прежние доступы и не удаляет чужие клоны. Замена токенов и паролей не заявляется выполненной этой публикацией.

## Данные для проверки

Снимок каталога содержит реальные события и сведения об их происхождении. Неизвестные значения и статусы сохранены. Переписки, контакты, подписки, идентификаторы пользователей, расходные квоты и административный журнал в снимок не переносятся. Таблицы пользовательского состояния оставлены пустыми для совместимости схемы. Подробный состав, дата и SHA256 приведены в `data`.

Рабочие резервные копии хранятся отдельно. Они могут содержать секреты и персональные данные, их нельзя добавлять в репозиторий или выдавать вместо обезличенной базы. Проверенные ранее процедуры восстановления описаны в [эксплуатации](operations.md) и [паспорте экземпляра](temporary-hosting.md). Снимок SQLite не является автоматической миграцией в PostgreSQL.

## Архив исходников

Для создания дополнительного ZIP без зависимостей, кешей, секретов и служебных инструкций выполните из корня:

```powershell
.venv/Scripts/python.exe scripts/package_release.py --output C:/Releases/kiber102-source
```

Выберите новый каталог вне проекта. Упаковщик создаёт ZIP и SHA256-манифест и отказывается перезаписывать готовый результат. Приватные рабочие данные добавляются только отдельным явным параметром и не являются частью исходников для сдачи.
