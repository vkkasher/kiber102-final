# Проверочные материалы

| Файл | Что подтверждает |
|---|---|
| `final-audit.json` | Последний комплексный аудит, проверки сборки, безопасности, браузера и границы соответствия PDF |
| `dialog-hardening.json` | Последующие исправления диалога, статьи с фотографиями и пагинацией в Telegram, 449 Python-тестов и границы живой проверки |
| `handoff.json` | Историческая проверка восстановления приватных резервных копий. Сами копии и конфигурации в итоговый репозиторий не входят |
| `publication.json` | Состав очищенной итоговой передачи, повторные проверки, поиск секретов и обезличенная база каталога |
| `validation.json` | Команды и результаты подготовки текущего комплекта |
| `evaluation.json` | 60 основных и 10 внутренних контрактов, baseline, fallback без платной модели |
| `source-quality.json` | Сверка 50 карточек и 500 полей с исходными SHA256-снимками |
| `deepseek-dialog.json` | Пять реплик через реальный DeepSeek и изолированную копию каталога, токены и расход |
| `deployment.json` | Проверка отдельного временного сервера и восстановления backup |
| `catalog-update.json` | Сверка изображений и продажи, миграция, 250 Python-тестов и проверка обновлённых страниц на телефоне и компьютере |
| `demo-5min.webm`, `demo-metadata.json` | Резервная запись конкретного запуска с датой и проверкой длительности |
| `screenshots/*.png` | Семь просмотренных кадров текущей резервной записи |
| `screenshots/embed-desktop.png`, `screenshots/embed-mobile.png` | Исправленная форма встраивания на публичном домене, проверенная на компьютере и телефоне |
| `sources/*.raw` | Четыре неизменённых исходных документа для воспроизведения проверки адаптеров |

Случаи для runner находятся в `tests/evals`, разметка источников в `docs/data/source-labels.json`. Человеческая проверка разметки не заявляется. Примеры на синтетических данных не являются публичной афишей. Исторический удачный ответ не подтверждает актуальность события сегодня. Границы приёмки описаны в [матрице](../acceptance.md).

## Проверка временного сервера

[deployment.json](deployment.json) фиксирует HTTPS, основные страницы, fallback, планировщик, Telegram getMe, восстановление backup и 20 readiness-запросов. Ответ DeepSeek и план дня дополнительно проверены через браузер на публичном домене. Отчёт не подтверждает доставку Telegram-сообщений, чистый Docker-старт или независимую приёмку по PDF.

Для проверки собранных данных в итоговой передаче доступен [обезличенный снимок каталога](../../data/README.md). Упоминания закрытых архивов и старых commit ID в датированных JSON-отчётах относятся к прежним проверкам, а не к составу этой публикации.
