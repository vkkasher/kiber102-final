# REST API

Контракт API имеет версию `v1`. Точные типы, ограничения и коды ответов находятся в [openapi.json](openapi.json), OpenAPI 3.1. На сайте интерактивная документация доступна по `/api/docs`, JSON по `/api/openapi.json`. При прямом доступе к backend это `/docs` и `/openapi.json`. Ресурсы Swagger включены в приложение и работают без внешнего CDN.

## Публичные методы

| Метод | Путь | Результат |
|---|---|---|
| GET | `/api/v1/events` | Поиск опубликованных актуальных событий |
| GET | `/api/v1/events/{event_id}` | Постоянная карточка, включая явно помеченную отмену |
| GET | `/api/v1/cities` | Массив городов |
| GET | `/api/v1/venues` | Массив площадок |
| GET | `/api/v1/categories` | Массив категорий |
| POST | `/api/v1/subscriptions` | Создание подписки, `201`, возвращает ID и токен удаления |
| DELETE | `/api/v1/subscriptions/{subscription_id}` | Удаление своей подписки по Bearer delete_token, `204` |
| POST | `/api/v1/feedback` | Обращение в очередь модерации, `201` |
| POST | `/api/v1/agent/query` | Диалог, карточки, уточнение, trace_id и состояние |
| POST | `/api/v1/agent/plan` | План 2–4 событий либо обоснованная несовместимость условий |
| GET | `/api/v1/health` | Проверка доступности API и БД |
| GET | `/api/v1/metrics` | Счётчики запросов, ошибок и задержек текущего процесса |

### Поиск

`q`, `city`, `category`, `venue`, `date_from`, `date_to`, `price_max`, `age`, `sort`, `page`, `page_size`. Даты ISO `YYYY-MM-DD`, включительно по Башкортостану. Сортировка `date` или `price`. Страница от 1, размер от 1 до 100, по умолчанию 20. Ответ имеет поля `items`, `total`, `page`, `page_size`.

Примеры ниже для Bash. `BASE` является адресом выбранного экземпляра.

```bash
BASE=http://127.0.0.1:8000
curl --get "$BASE/api/v1/events" \
  --data-urlencode 'city=Уфа' \
  --data-urlencode 'category=спектакль' \
  --data 'page=1&page_size=5&sort=date'
curl "$BASE/api/v1/cities"
curl "$BASE/api/v1/events/$EVENT_ID"
```

Пример настоящей карточки временного экземпляра. GET ниже вернул HTTP `200` 14 ноября 2026 года в 17:46 UTC, 15 ноября по времени владельца. Ответ сокращён до основных полей. Данные отражают момент проверки, цены и статус могут измениться.

```bash
curl https://kiber102.vkkasher.ru/api/v1/events/b953affd-0cb5-4c46-91b2-7da997a0bcb5
```

```json
{
  "id": "b953affd-0cb5-4c46-91b2-7da997a0bcb5",
  "title": "Палата бизнес-класса",
  "category": "спектакль",
  "date_start": "2026-11-18T14:00:00Z",
  "date_end": "2026-11-18T21:20:00+05:00",
  "city": "Уфа",
  "venue": "Русский драматический театр РБ",
  "address": "Уфа, проспект Октября, 79",
  "price_min": 300.0,
  "price_max": null,
  "is_free": false,
  "age_limit": 16,
  "source_url": "https://rusdram.ru/afisha.html",
  "ticket_availability": "available",
  "ticket_checked_at": "2026-11-14T17:13:24.097543Z",
  "status": "published"
}
```

`price_max` в обычном каталоге сравнивается с известной минимальной ценой одного билета. Он не гарантирует полную стоимость группы. Агент и планировщик проверяют известную верхнюю цену для всей компании. Неизвестная цена не превращается в бесплатный вход. Неопубликованная или непроверенная карточка возвращает `404`.

Карточка также возвращает `image_url`, `image_source_url`, `ticket_availability` и `ticket_checked_at`. Эти поля могут быть `null`. Изображение конкретного сеанса связано со страницей его происхождения. Лицензированный `poster_url` с `poster_rights` имеет приоритет. Значения `sold_out`, `off_sale`, `cancelled`, `rescheduled` исключают сеанс из поиска и подборок. Постоянная карточка остаётся доступной с пояснением. Ошибка загрузки или неизвестное наличие билетов не означает распродажу.

Для кнопок покупки используйте `ticket_links`. Пустой массив означает отсутствие доступных ссылок продажи, даже если исторический `org_link` сохранён в карточке.

Цена и окончание могут уточняться свежей записью конкретного сеанса. Сравниваются название, город, площадка и время начала. Нижняя цена без опубликованного максимума возвращается с `price_max=null`, поэтому не гарантирует бюджет всей группы. Время проверки сохраняется в API, хотя в публичной карточке служебные отметки не показываются.

### Диалог

```bash
curl "$BASE/api/v1/agent/query" --json \
  '{"message":"Что посмотреть в Уфе с ребёнком 8 лет до 1500 рублей?"}'
```

Ответ содержит `text`, `events`, `question`, `state`, `trace_id`, `mode`, `tool_calls`, `dialog_id`, `explanations`, `pending_action`, `action_result`, `plan`. Следующая реплика передаёт возвращённые `state` и `dialog_id`. `offline:true` явно отключает модель. `mode=fallback` является рабочим резервным режимом. Для подтверждения действия передайте возвращённый nonce в `confirmation_nonce`, не создавайте его на клиенте.

Самостоятельные запросы вроде «В Уфе завтра» или «Куда пойти завтра?» начинают новую подборку без прежнего бюджета, возраста и названия. Если город не повторён, сохраняется известный город. Короткие уточнения «на субботу», «до 2000 рублей», «мне 18 лет» и «а в Салавате?» меняют текущие условия. «А ещё» продолжает выдачу. Дни и часы считаются по Башкортостану. Старые ошибочные фрагменты названия вроде «Мне» очищаются при следующем запросе.

`result_limit` задаёт от 1 до 5 событий в ответе, по умолчанию 5. Бот использует 3. Для поиска `state.result_count` содержит полное число событий, прошедших проверку условий до отсечения предыдущих страниц. Основания счётчика сохраняются в `trace.pagination`. Следующая страница использует возвращённое состояние и «а ещё», без ослабления ограничений.

План принимает `city`, `date`, `window_start`, `window_end`, `budget`, `adults`, `children_ages`, `max_travel_minutes`, необязательные `interests` и `event_count`. Бюджет относится к билетам всей группы. Неизвестные цена, окончание или маршрут могут сделать план неподтверждаемым. `feasible:false` не является сетевой ошибкой.

Отдельный запрос `/api/v1/agent/plan` сохраняет трассу для просмотра через `/api/v1/admin/traces`. В текущем `PlanOutput` нет поля `trace_id`. Сопоставляйте запись по её `request_id` и заголовку `X-Request-ID` HTTP-ответа.

### Подписки и обращения

Подписка принимает `city`, необязательные `category` и `period`. Сохраните `delete_token`, он нужен для удаления. Служба хранит его хеш. Telegram-получатель определяется только по подписанной внутренней идентичности. Обращение принимает `message`, необязательные `event_id`, `contact`, `website`. Последнее поле служит антиспам-ловушкой. POST обращения поддерживает `Idempotency-Key`.

## Административные методы

`POST /api/v1/admin/login` принимает `{username,password}` и возвращает `token`, `expires_in`, `actor`, `role`. Срок токена 28 800 секунд. Все последующие административные методы требуют `Authorization: Bearer <token>`. Клиентская cookie посетителя не даёт административных прав.

| Метод | Путь после `/api/v1/admin` | Назначение |
|---|---|---|
| GET / POST | `/events` | Очередь с фильтрами / ручное создание черновика |
| PATCH | `/events/{event_id}` | Редактирование и модерация статуса |
| POST | `/events/{event_id}/verify` | Проверка разрешённого первоисточника |
| POST | `/import` | CSV/JSON и построчный отчёт |
| POST | `/ticket-evidence` | Сверка снимка Кассы.ру с конкретным существующим сеансом |
| GET | `/audit` | Журнал действий |
| GET | `/traces` | Трассы ответов агента |
| GET / PATCH | `/sources`, `/sources/{source_id}` | Источники и их доступность |
| GET / PATCH | `/feedback`, `/feedback/{feedback_id}` | Очередь обращений и рассмотрение |
| POST | `/maintenance` | Применение сроков хранения |
| POST | `/notifications/enqueue` | Подготовка очереди уведомлений |
| POST | `/notifications/claim` | Получение заданий с lease |
| POST | `/notifications/{notification_id}/ack` | Подтверждение результата доставки |

Точные права `viewer`, `moderator`, `admin` проверяются сервером. Импорт принимает `{format:"csv"|"json",content:string}`. CSV допускает запятую, точку с запятой и табуляцию. Веб-загрузка CSV поддерживает UTF-8 и Windows-1251, JSON только UTF-8. Пределы 2 МБ и 1000 строк. Ответ различает added, updated, rejected, duplicate и requires_review. Повтор не создаёт дубли, публикация требует отдельной проверки.

`ticket-evidence` принимает `{source_url,content,sha256}`. SHA256 проверяется по UTF-8 содержимому. Допускаются только публичные страницы конкретных сеансов двух настроенных доменов Кассы.ру и известные площадки. Метод не создаёт события и не меняет решение модератора. Ответ содержит `matched`, при совпадении также `event_id` и `availability`. Снимок, хеш, время и основание совпадения сохраняются в БД и аудите. Ошибка хеша возвращает `422`, отсутствие точного единственного совпадения возвращает `matched:0`.

## Ошибки, кэш и защита

```json
{"code":"validation_error","message":"Проверьте поля запроса","details":[],"request_id":"…"}
```

Используются `401`, `403`, `404`, `409`, `413`, `422`, `429`, `503` по причине отказа. При ограничении частоты может возвращаться `Retry-After`. В HTTP-ответе есть `X-Request-ID`. Карточки и справочники возвращают заголовки кэширования, изменяющие запросы не кэшируются. Поля неизвестных данных имеют `null`, а не правдоподобные значения.

Не передавайте клиентские `X-Client-*` заголовки как доверенные. Proxy Next.js и бот подписывают собственную идентичность общим секретом, backend её проверяет. HTTP-порты backend должны оставаться внутренними. Встраивание выполняется через `/embed` и изолированный `/widget`, без зависимости от сторонних cookies.
